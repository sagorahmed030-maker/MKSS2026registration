GitHub Pages + Supabase সেটআপ

সব ওয়েবসাইট কোড এই একটিমাত্র index.html ফাইলে আছে। GitHub-এ আর কোনো ফাইল লাগবে না।

সতর্কতা: এই সেটআপ ছাড়া রেজিস্ট্রেশন অনলাইনে জমা হবে না। Supabase-এর publishable/anon key প্রকাশ করা যায়; service_role বা secret key কখনো HTML-এ বসাবেন না।
  1. Supabase-এ Free Project তৈরি করুন।
  2. Authentication → Providers → Anonymous Sign-ins চালু করুন। Email/password sign-in-ও চালু রাখুন।
  3. SQL Editor → New query খুলে নিচের SQL কপি ও Run করুন।
  4. Authentication → Users → Add user দিয়ে অ্যাডমিন ইমেইল/পাসওয়ার্ড বানান। User UUID কপি করুন।
  5. SQL Editor-এ চালান: insert into public.mkss_staff(user_id,role) values ('YOUR-USER-UUID','admin');
  6. Supabase Project Settings → API / Connect থেকে Project URL এবং Publishable/anon key নিন; এই HTML-এর শুরুতে SUPABASE_URL, SUPABASE_KEY বদলান।
  7. এই একটিমাত্র index.html GitHub repository-র root-এ আপলোড করুন। Settings → Pages → Deploy from a branch → main / (root) করুন।
  8. প্রকৃত তথ্য দেওয়ার আগে রেজিস্ট্রেশন, পেমেন্ট যাচাই, অনুমোদন, কার্ড উদ্ধার, QR ও duplicate scan পরীক্ষা করুন।
লোড হচ্ছে...

ফ্রি Supabase প্রকল্প নিষ্ক্রিয় থাকলে pause হতে পারে। লাইভ ইভেন্টের আগে সক্রিয় আছে কিনা দেখুন। এটি স্বয়ংক্রিয় পেমেন্ট ভেরিফিকেশন নয়। পাবলিক ফর্মের জন্য অতিরিক্ত anti-bot / rate-limiting প্রয়োজন হতে পারে।
